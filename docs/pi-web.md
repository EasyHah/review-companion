# agegr/pi-web 兼容

本包适配 `@agegr/pi-web` 0.11.0 / Pi 1.1.0 的本机浏览器用法。Pi Web 与浏览器在同一台电脑运行；远程访问时的回顾服务代理、手机连接不包含在这一版。0.3.6 配套侧栏版可同页内嵌回顾面板，见 ../adapters/pi-web/README.md。

## 安装和配置

沿用现有 `~/.pi/agent`，或使用者已有的 `PI_CODING_AGENT_DIR`。不要为 Pi Web 新建回顾专用 Pi 配置，不复制凭证，不改默认模型。按包根 INSTALL.md 将本包注册为 Pi package；旧回顾 package 只保留一个启用来源，其他插件保留。

Pi Web 可以安装到使用者选择的独立应用目录，但它仍读取同一个 Pi 配置目录。已安装时不要再装另一份。安装前检查版本与安装脚本；本次验证版本为 `@agegr/pi-web@0.11.0`。Web 自带的 Pi SDK 版本也要核对，升级全局 `pi` 不会同时升级 Web 内置 SDK。

启动 Pi Web 后，在其网页选择实际业务项目。使用正常工具预设；**Chat only 不加载 Pi 扩展**，因此不能用回顾工具或扩展注册的门神分流模型。

## 使用

配套侧栏版：点击 Pi Web 顶部“回顾”，在右侧查看当前聊天对应的回顾；可在栏内切换文件、终端和回顾，支持原有拖宽、展开、收起。换聊天后跟随当前会话，不保留旧会话 iframe。需要完整重启服务并刷新页面；原版 Pi Web 继续使用独立链接。

- 新回顾：发送“使用回顾伴随，梳理当前开发分支相对主分支的功能变化，并打开回顾总览”。
- 已有回顾：输入 `/review`，点击聊天里显示的“打开回顾总览”。也可点击输入框下方的回顾状态按钮。
- `/review doctor` 查看依赖、版本和模型限制；`/review-config` 查看门神认证来源提示。
- 面板的“请解释／下一份”复制问题，用户粘贴回 Pi Web 后发送。不会调用网页输入框写入接口，也不等待无法完成的草稿确认。
- 默认仍用当前模型；需要自动分流时在模型选择器手动选择“门神回顾自动分流”。

Web 会话各自拥有回顾连接和访问令牌；同项目共享持久记录，不同项目分别保存。重载一个会话不影响其他会话。终端 TUI 的新会话继续复用其面板入口；Web/RPC 的新会话使用独立入口。Web 关闭闲置会话后，旧回顾链接可能失效，再执行 `/review` 获取当前链接即可。

升级后完整重启 Pi Web 服务和需要更新的 Pi 进程，再打开回顾面板。只刷新网页不会更新已经加载的扩展。不要停止尚在工作的会话而不告知使用者。

## 验证范围

自动验证真实 Pi Web 服务的三个并行会话、扩展命令和工具发现、回顾链接、同项目记录共享、跨项目隔离、复制模式、重载隔离及原模型/配置保留。全部使用临时合成项目，不发送外部模型请求。

真实门神推理效果、浏览器可见界面、剪贴板与 VS Code 窗口由用户试用验收。主机侧源码/Diff仍使用固定提交；Pi Web 自带当前工作区 Git Diff 不代替固定版本证据。
